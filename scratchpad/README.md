# scratchpad

Working notes. **Nothing here is canonical.**

| If it is… | It belongs in… |
|---|---|
| a decision | `decisions/` |
| current state or open work | `STATUS.md` |
| what we're building | `DESIGN.md` |
| a working note, a draft, a session handoff | here |

Files are dated (`YYYY-MM-DD-<slug>.md`) and go stale on purpose. A scratchpad file that
contradicts `STATUS.md` is wrong by definition — `STATUS.md` wins.

**Delete freely.** If something here turns out to matter, promote it to one of the canonical
documents rather than letting this folder grow into a second source of truth. V1 died of having
several documents that all answered the same question slightly differently.
