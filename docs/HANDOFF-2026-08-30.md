## 0. The trap that cost this session an hour

`../Sapien Paradox App` (V1) and produced a full backend architecture pass — grilling model drift,
open PRs and failing tests — before the user asked *"are we clear this is V2?"* and the answer was
no. None of it applied.

Both repos now open by asking **"Is this session for V1 or V2?"** via
`.claude/hooks/session-start.sh`. V2's hook also lists every tracked markdown file, because the
other half of the failure was that `REBUILD.md` and `STATE_MACHINE_DESIGN.md` existed in V1 and
nothing advertised them. `CLAUDE.md` now `@`-imports `STATUS.md`, `DESIGN.md` and
`decisions/README.md` so the index is in context rather than merely recommended.

**If a future session starts describing V1's models as problems to solve, it is in the wrong repo.**

## 4. External services — validated, with real calls

Both proven end to end during this session. **Credentials are in `apps/api/.env` in the V1 repo**
(`../Sapien Paradox App/backend/.env`), gitignored — they have not been copied into V2.

| Service | Evidence | Caveat |
|---|---|---|
| **Razorpay** | A real ₹10 payment completed — `plink_TVf5nhHQomnoOh`, status `paid` | Test mode is **domestic-only**. `4111 1111 1111 1111` is rejected as an international card; use `5267 3181 8797 5449`, or Netbanking, or UPI `success@razorpay`. Test OTP `1111` |
| **Twilio WhatsApp** | A real message reached a handset — status `delivered`, free-form, 1 segment, ₹0 | Trial account. The recipient's number has joined the sandbox |

**Two findings that change the product plan:**

**WhatsApp has no anchor-text hyperlinks.** It auto-linkifies real URLs only — a `localhost` link
renders as plain text, which is why chapter links need a publicly reachable `FRONTEND_URL` before
any demo on a phone.

**Every cadence message is business-initiated**, so it is always outside the 24-hour window. That
makes **two Meta-approved templates mandatory** in production — chapter unlock and the unread
reminder. Sandbox plus free-form is fine only for a demo where every recipient has typed the join
code.

There is also a **spike harness** at `../Sapien Paradox App/spikes/razorpay/` — stdlib-only, no
dependencies — that creates a live payment link and proves the return-trip parameters.

## 5. Gotchas that cost real time

Each of these was a dead end before it was a fix. Most are now recorded in the per-app `CLAUDE.md`
files, but they are collected here because they read as a set.

### XState v5

- **`machine.provide()` does not typecheck** when implementations live in sibling files. `assign`
  called outside the machine widens its event to `EventObject`; `provide` wants the machine's own
  union, so every context updater is rejected. Use **`setup()`**, and apply `assign` in `index.ts`
  over plain functions exported from `actions.ts`. The file split is unchanged.
- **An actor's result arrives as `event.output`**, not as one of your events. A single updater
  shared between `onDone` and a hand-sent event silently leaves context null on the actor path —
  which looks exactly like being logged out. This shipped as a real bug twice before the tests
  caught it.
- **Annotating `invoke.input` with a shape narrower than the event union breaks inference for the
  whole machine.** `state.matches("submitting")` then reports `never` rather than pointing at the
  annotation. Narrow from the union inside the function instead.
- **`as const` on a machine config is required** so `type: "parallel"` stays a literal — but it also
  freezes `books: []` to `readonly []`, which the machine's `Context` rejects. Hoist the context to
  an annotated const outside the object.

### Tooling

- **Vitest 2 bundles Vite 5** and collides with this app's Vite 6 the moment a `test` key is added
  to `vite.config.ts`. Vitest 3 is required. Import `defineConfig` from `vitest/config`.
- **Tests need jsdom** — the navigation actions touch `window.history`.
- **Do not name a management-command flag `--stdout`.** Django's `BaseCommand` owns `self.stdout`
  and argparse overwrites it with a boolean, failing on the first write.
- **`transitions` logs every callback at INFO** and every ignored trigger at WARNING. Ignored
  triggers are normal by design here, so the logger is quieted to ERROR.

## 6. Two departures that want a second opinion

Both changed the signed-off architecture during implementation, and both are argued in their PR
bodies and walkthroughs rather than buried.

**Expiry is not a state** (#20). The report had `expired` as a fourth terminal state. Building it
showed expiry is *derived* from `expires_at`, which the model already knows — storing it as well
would need a sweeper keeping the two agreeing, which is the duplication this layer exists to
remove. `OPEN` on an expired grant refuses without moving; sanctuary is chosen from the refusal
code.

**No `react-pdf`** (#31). `PdfChamber` fetches the proxied bytes from `/api/grants/{token}/pdf` and
renders from a blob URL. The native viewer is enough to read a chapter. V1 used `react-pdf`, so
this is a genuine change, reversible if page-level features need it.

## 7. The one thing the tables caught that prose had hidden

D26's identity rules are a page of careful reasoning. Written as an ordered table, the row order
turned out to be wrong: the plain exact-match row fired **before** the already-owns-the-book check,
making `duplicate_order` unreachable — a returning reader would have been **silently charged
twice**.

The rule was written correctly and implemented in the wrong order, and only the ordered rows showed
it. If the machine layer needs one argument, this is it.

## 8. What to do next

In order, and the first is not code:

1. **Merge the stacks bottom-up**, or say they are too large and want re-cutting. Nothing above the
   base of each stack can land otherwise.
2. **Build the three seams** — `access.can_read`, `onboarding.create_reader`,
   `whatsapp.send_chapter`. They are locked as D25–D27 and written nowhere, and every machine is
   waiting on them.
3. **`seed_dev`**, so there is data to run against.
4. **Auth endpoints**, which makes #38–#40 run against a real backend and gives the first thing you
   can actually see.
5. **Deploy** — still the oldest unpaid debt, and D5 says deploy before there is much to deploy.

**Track A has not started and cannot be compressed:** the domain, then Meta business verification
(days to weeks), then the four template approvals. Razorpay KYC runs on its own clock. Nothing
customer-facing ships until those clear.
